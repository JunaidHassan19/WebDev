Terminal Basics

A terminal is a text-based interface used to interact with the computer or operating system. It allows you to run commands, manage files, install software, and work with projects without using a graphical interface.

Different terms related to the terminal:

1. Command Prompt / Shell
   - A command-line environment that accepts text commands.
   - Examples: Bash, Zsh, PowerShell, CMD.

2. Terminal
   - The application window where you type commands.
   - It connects you to the command-line interface.

3. Command
   - An instruction typed into the terminal to perform a task.
   - Example: ls, cd, pwd, mkdir.

4. Directory
   - A folder in the file system.

5. Working Directory
   - The current folder where terminal commands are being executed.

6. Path
   - The location of a file or folder in the system.
   - Example: C:\Users\Name\project

7. Root Directory
   - The top-level folder in the file system.
   - In Linux/macOS it is / ; in Windows it may be C:\.

8. Relative Path
   - A path that is relative to the current directory.
   - Example: ./project or ../folder

9. Absolute Path
   - A full path from the root to the file or folder.
   - Example: /home/user/project

10. CLI (Command Line Interface)
   - A way of interacting with a computer by typing commands instead of using a GUI.

11. Bash
   - A popular Unix shell used in many terminals.

12. PowerShell
   - A shell used mainly on Windows systems.

13. Terminal Output
   - The text result returned after running a command.

14. Arguments
   - Extra information passed to a command.
   - Example: ls -l

15. Flags / Options
   - Symbols that change the behavior of a command.
   - Example: -l, -a, -h

Navigation commands and paths:

1. pwd
   - Prints the current working directory.

2. ls
   - Lists files and folders in the current directory.

3. ls -l
   - Lists files in long format, showing extra details.

4. ls -a
   - Lists all files including hidden ones.

5. cd foldername
   - Changes into a folder.

6. cd ..
   - Goes back to the parent directory.

7. cd /
   - Goes to the root directory.

8. cd ~
   - Goes to the home directory.

9. ./foldername
   - Refers to a folder or file in the current directory.

10. ../foldername
   - Refers to a folder or file in the parent directory.

11. clear
   - Clears the terminal screen.

Making directories:

1. mkdir foldername
   - Creates a new directory.

2. mkdir folder1 folder2
   - Creates multiple directories at once.

3. mkdir -p folder/subfolder
   - Creates nested directories automatically.

4. rmdir foldername
   - Removes an empty directory.

5. rm -r foldername
   - Removes a directory and everything inside it (be careful).

Touch command:

1. touch filename.txt
   - Creates a new empty file.

2. touch file1.txt file2.txt
   - Creates multiple new files at once.

3. touch -t 202401010101 file.txt
   - Changes the timestamp of a file.

Deleting files and folders:

1. rm filename.txt
   - Deletes a file.

2. rm -rf foldername
   - Deletes a folder and its contents without asking for confirmation.

3. del filename.txt
   - Deletes a file in Windows Command Prompt.

4. Remove-Item filename.txt
   - Deletes a file in PowerShell.

5. Remove-Item -Recurse foldername
   - Deletes a folder and everything inside it in PowerShell.

Basic terminal commands:

1. pwd
   - Print the current working directory.

2. ls
   - List files and folders in the current directory.

3. mkdir foldername
   - Create a new directory.

4. cd foldername
   - Change into a folder.

5. cd ..
   - Go back to the parent directory.

6. touch filename.txt
   - Create a new empty file (Linux/macOS).

7. type nul > filename.txt
   - Create a new empty file (Windows Command Prompt).

8. rm filename.txt
   - Delete a file.

9. rmdir foldername
   - Remove an empty directory.

10. clear
   - Clear the terminal screen.

11. echo "text"
   - Print text to the terminal.

12. cp source.txt destination.txt
   - Copy a file.

13. mv oldname.txt newname.txt
   - Move or rename a file.

14. cat filename.txt
   - Show the contents of a file.

15. man command
   - Show help or documentation for a command.

16. help
   - Display help information in some shells.

17. git status
   - Check the status of a Git repository.

18. git init
   - Initialize a new Git repository.

19. npm install
   - Install project dependencies.

20. node filename.js
   - Run a JavaScript file using Node.js.

What are flags?

Flags are extra options added to commands to change their behavior. They usually start with a - sign.

Examples:
- ls -l -> shows detailed file information
- ls -a -> shows hidden files
- rm -r folder -> deletes a folder and its contents
- mkdir -p folder/subfolder -> creates nested folders automatically

Important note:
- Flags are useful because they give more control over a command.
- They can change how a command works or what information it shows.

Why terminal is important?
- It helps developers manage files faster.
- It is used for Git, Node.js, package installation, and server commands.
- It is essential for backend development, automation, and debugging.

Quick example:

pwd
ls
cd project
mkdir test
cd test
pwd

This sequence shows how to check the current folder, list contents, move into a directory, create a new folder, and confirm the working location.

Summary:
The terminal is a powerful tool for working efficiently with the computer. Learning navigation commands, paths, directory creation, flags, and deletion commands will help you manage files and folders more confidently.
