Node.js
========

What is Node.js?
----------------
Node.js is a JavaScript runtime environment that allows JavaScript to run
outside the browser. It is built on Chrome's V8 JavaScript engine and is
commonly used to create backend applications, APIs, command-line tools, and
real-time applications.

Important features:
- Open source and cross-platform
- Fast because it uses the V8 engine
- Asynchronous and event-driven
- Uses non-blocking I/O operations
- Uses JavaScript on both the frontend and backend

Installing Node.js
------------------
1. Download Node.js from https://nodejs.org.
2. Install the LTS version.
3. Verify the installation:

node -v
npm -v

The `node` command runs JavaScript files. npm (Node Package Manager) is used
to install packages and manage project dependencies.

Running a JavaScript file
-------------------------
Create a file named app.js:

console.log("Hello from Node.js");

Run it from the terminal:

node app.js

Node.js modules
---------------
A module is a reusable piece of code. Node.js provides built-in modules such
as:
- fs: works with files and folders
- http: creates HTTP servers
- path: works with file and directory paths
- os: provides operating system information
- events: works with event-driven programming

Example of using a built-in module:

const os = require("os");

console.log(os.platform());
console.log(os.cpus().length);

Modern projects can also use ES module syntax:

import os from "os";

npm and package.json
-------------------
Create a new Node.js project with:

npm init -y

This creates a package.json file. It stores project information, scripts, and
dependencies.

Install a package:

npm install package-name

Install a development-only package:

npm install package-name --save-dev

Run a project script with:

npm run script-name

Simple HTTP server
------------------
The following program creates a web server on port 3000:

const http = require("http");

const server = http.createServer((request, response) => {
	response.writeHead(200, { "Content-Type": "text/plain" });
	response.end("Hello from the Node.js server");
});

server.listen(3000, () => {
	console.log("Server running at http://localhost:3000");
});

Save the code in server.js and run:

node server.js

Open http://localhost:3000 in a browser. Stop the server with Ctrl+C.

Asynchronous programming
------------------------
Node.js uses callbacks, promises, and async/await to handle asynchronous
operations without blocking the main thread.

Example:

const fs = require("fs");

fs.readFile("file.txt", "utf8", (error, data) => {
	if (error) {
		console.log(error.message);
		return;
	}

	console.log(data);
});

Common uses of Node.js
---------------------
- REST APIs and backend services
- Web servers
- Chat and real-time applications
- Streaming applications
- Command-line tools
- Microservices

Node.js is not usually used for heavy CPU-based tasks because a long-running
calculation can block its main event loop. Worker threads or separate services
can be used for such tasks.
