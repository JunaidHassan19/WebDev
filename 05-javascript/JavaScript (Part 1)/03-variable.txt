======================================================
           TOPIC: WHAT IS A VARIABLE?
======================================================

1. THE BASIC DEFINITION
-----------------------
In programming, a variable is simply a "container" used to store data values in a computer's memory. 

Think of a variable as a labeled box:
- You put something inside the box (the data or value).
- You write a name on the outside of the box (the variable name or identifier).
- Whenever you need what's inside, you just call out the name on the label.

2. WHY DO WE NEED THEM?
-----------------------
- To store information that might change later (like a user's age or a game score).
- To make code reusable. Instead of typing the number "10" a hundred times, you can just use a variable named 'a' and change it in one place if needed.
- To make code readable. 'age = 23' makes much more sense to a human than just a random '23' floating in the code.

3. EXAMPLES (JAVASCRIPT / CONSOLE)
-----------------------
Here is how variables look when you assign data to them:

a = 10          // Storing a number
b = 5           // Storing another number
age = 23        // Storing a specific metric
name = "tony"   // Storing text (called a String). Notice the quotes!

4. HOW THE COMPUTER READS IT
-----------------------
If you type:
age = 23

The computer thinks: "Okay, I will find a small empty space in my memory, label that space 'age', and place the number 23 inside it. If they ever type 'age' again, I will give them the number 23."

5. KEY RULES FOR VARIABLES (Standard across most languages)
-----------------------
- They cannot have spaces in their names (e.g., 'user age' is invalid, 'userAge' is valid).
- They are usually case-sensitive ('Age' and 'age' are two different boxes).
- You can change the value inside the box at any time (hence the name "variable", because it can vary).
