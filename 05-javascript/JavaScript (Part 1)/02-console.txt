=========================================
      USING THE JAVASCRIPT CONSOLE
=========================================

1. WHAT IS THE CONSOLE?
The console is a powerful developer tool built into all modern web browsers (like Chrome, Firefox, Edge, and Safari). It acts as an interactive command line for your web page, allowing you to write, execute, and test JavaScript code in real-time. It is also where the browser displays messages, errors, and warnings about your code.

2. HOW TO OPEN THE CONSOLE
- Google Chrome / Edge: 
  Right-click anywhere on a webpage -> Select "Inspect" -> Click the "Console" tab. 
  (Keyboard Shortcut: Ctrl + Shift + J on Windows/Linux, Cmd + Option + J on Mac).
- Mozilla Firefox: 
  Right-click -> Select "Inspect" -> Click the "Console" tab.
- Apple Safari: 
  First, enable the Develop menu (Safari > Settings > Advanced > Check "Show Develop menu"). Then press Cmd + Option + C.

3. WHY DO DEVELOPERS USE IT?
- Debugging: If your JavaScript code isn't working as expected, the console is the first place you check. It will often highlight syntax errors or logical faults in red.
- Quick Testing: You can type small snippets of JavaScript directly into the console and press Enter to see the immediate result, skipping the need to save and refresh a separate file.
- Logging Data: Developers use it to print out the hidden values of variables behind the scenes to ensure the data is flowing correctly.

4. COMMON CONSOLE COMMANDS
The `console` object in JavaScript comes with several built-in methods to help organize your output:

- console.log()
  Prints standard output or general messages. 
  Example: console.log("User clicked the button.");

- console.error()
  Prints an error message, usually styled in red to grab your attention.
  Example: console.error("Failed to load user data!");

- console.warn()
  Prints a warning message, usually styled in yellow. Used for things that aren't fatal errors but should be fixed.
  Example: console.warn("This feature will be deprecated soon.");

- console.clear()
  Clears the console of all previous output, giving you a clean slate.
  Example: console.clear();
