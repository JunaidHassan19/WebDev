======================================================
           TOPIC: NUMBERS IN JAVASCRIPT
======================================================

1. THE BASICS: ONE TYPE RULES THEM ALL
-----------------------
Unlike some other programming languages that have different types for whole numbers (integers) and decimals (floats), JavaScript only has one main data type for numbers: Number.

Whether it has a decimal or not, JavaScript treats it as a Number.

let age = 20;        // Whole number (Integer)
let price = 19.99;   // Decimal number (Float)

2. BASIC MATH OPERATIONS
-----------------------
You can perform all standard mathematical operations using JavaScript:

+   Addition           (10 + 5 = 15)
-   Subtraction        (10 - 5 = 5)
* Multiplication     (10 * 5 = 50)
/   Division           (10 / 5 = 2)
%   Modulo/Remainder   (10 % 3 = 1)  // 10 divided by 3 leaves a remainder of 1
** Exponentiation     (10 ** 2 = 100) // 10 to the power of 2

3. SPECIAL NUMERIC VALUES
-----------------------
JavaScript has a few special "numbers" that you might encounter:

- NaN (Not a Number): 
  This happens when you try to do math with something that isn't a number.
  Example: "apple" / 2  // Result: NaN

- Infinity / -Infinity: 
  This happens if you calculate a number too big for JavaScript to handle, or if you divide by zero.
  Example: 1 / 0        // Result: Infinity

4. CHANGING STRINGS TO NUMBERS
-----------------------
Sometimes numbers get stored as text (Strings), like "25". You can convert them back to real numbers:

- parseInt(): Converts text to a whole number.
  Example: parseInt("25.99") // Result: 25

- parseFloat(): Converts text to a decimal number.
  Example: parseFloat("25.99") // Result: 25.99

- The Number() function: Converts the whole thing.
  Example: Number("100") // Result: 100

5. THE 'Math' OBJECT (Built-in Helper)
-----------------------
JavaScript comes with a built-in Math toolkit for complex calculations:

Math.round(4.6)    // Result: 5 (Rounds to nearest whole number)
Math.floor(4.9)    // Result: 4 (Always rounds DOWN)
Math.ceil(4.1)     // Result: 5 (Always rounds UP)
Math.max(10, 20)   // Result: 20 (Finds the highest number)
Math.random()      // Result: A random decimal between 0 and 1
