## Overview

This folder contains my complete **JavaScript learning journey**. It begins with variables, data types, operators, and control flow, then moves through arrays, objects, functions, the DOM, browser events, promises, asynchronous code, and API requests.

## Quick Start

### Run a JavaScript File

Open any `.js` file in a browser-based HTML example or run it with Node.js:

```bash
node "05-javascript/JavaScript (Part 2)/conditional-statements.js"
```

### Run a Browser Example

1. Open an `index.html` file from the relevant part.
2. Make sure its `<script>` tag points to the correct JavaScript file.
3. Open the HTML file in a browser.
4. Use the browser DevTools Console to view output and errors.

For API examples, use a browser or a local server so that Fetch and Axios requests behave consistently.

## JavaScript Reference

### Common DOM Operations

```javascript
const heading = document.querySelector("h1");
heading.textContent = "Updated heading";
heading.classList.add("active");

const button = document.querySelector("button");
button.addEventListener("click", () => {
  console.log("Button clicked");
});
```

### Common Array Methods

| Method      | Purpose                              |
| ----------- | ------------------------------------ |
| `forEach()` | Runs a function for every item       |
| `map()`     | Creates a new transformed array      |
| `filter()`  | Creates an array from matching items |
| `reduce()`  | Combines items into one result       |
| `find()`    | Returns the first matching item      |
| `sort()`    | Reorders array items                 |

### Asynchronous Request Pattern

```javascript
async function getData(url) {
  try {
    const response = await fetch(url);
    const data = await response.json();
    return data;
  } catch (error) {
    console.error(error);
  }
}
```
