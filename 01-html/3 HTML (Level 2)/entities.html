HTML Entities

HTML entities are used to represent special characters in HTML. They start with an ampersand (&) and end with a semicolon (;). For example, the less-than symbol (<) is represented as &lt; and the greater-than symbol (>) is represented as &gt;.

Here are some common HTML entities:

  • &lt; - Less than sign
  • &gt; - Greater than sign
  • &amp; - Ampersand
  • &quot; - Quotation mark
  • &apos; - Apostrophe
