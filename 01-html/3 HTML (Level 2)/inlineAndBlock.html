Inline v/s Block Elements

HTML elements are categorized into two types: inline and block elements.

Block Elements

Block elements take up the full width available and start on a new line. Examples include:

  • <div>
  • <h1> to <h6>
  • <p>
  • <ul> and <ol>
  • <section>
  • <article>

Inline Elements

Inline elements do not start on a new line and only take up as much width as necessary. Examples include:

  • <span>
  • <a>
  • <strong>
  • <em>
  • <img>
  • <input>
