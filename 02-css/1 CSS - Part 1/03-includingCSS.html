How Inline CSS Works

Inline CSS uses the style attribute directly within an HTML tag. Each style declaration is a property-value pair, separated by a colon, and multiple declarations are separated by semicolons.

Example: <p style="color: red; font-size: 14px;">...</p>

Pros and Cons of Inline CSS

Pros:

  • Quick for testing or applying a very specific style to a single element.
  • Has the highest specificity, so it will override styles from internal or external stylesheets.

Cons:

  • Bad Practice for Maintenance: It mixes content (HTML) with presentation (CSS), making the code harder to read and maintain.
  • Not Reusable: You have to repeat the styles for every element you want to style the same way.
  • No Caching: Unlike external stylesheets, inline styles are not cached by the browser.

How Internal CSS Works

Internal CSS is defined within a <style> tag, which is typically placed in the <head> section of the HTML document. This allows you to write CSS rules that apply to the entire page.

Example (in head): <style> p { color: green; } </style>

Pros and Cons of Internal CSS

Pros:

  • Single-File Styling: Styles are contained within the HTML file, which can be convenient for single-page websites or components.
  • Affects the Whole Page: It can style any element on the page, unlike inline CSS which only affects one element.
  • No Extra HTTP Request: Since the styles are in the HTML file, the browser doesn't need to make an extra request to fetch a stylesheet.

Cons:

  • Not for Multi-Page Sites: If you want to use the same styles across multiple pages, you would have to copy the style block to every page, which is inefficient.
  • Page Load Speed: It increases the size of the HTML file, which can slightly increase page load time compared to a cached external stylesheet.
