The letter-spacing Property

This property controls the space between characters in a text.

Examples:

Normal: This is the default letter spacing.

Wide (3px): This increases the space between letters, which can be used for stylistic headings.

Tight (-1px): This reduces the space between letters, creating a more condensed look.
