CSS Font Properties

This page demonstrates the font-weight and text-decoration properties.

The font-weight Property

This property sets how thick or thin characters in a text should be displayed.

Normal (400): This is the default font weight. Lorem ipsum dolor sit amet.

Bold (700): This is the standard bold font weight. Lorem ipsum dolor sit amet.

Lighter (e.g., 300): A lighter weight than normal. (Requires font support)

Heavier (e.g., 900): A very heavy, or "black", font weight. (Requires font support)

The text-decoration Property

This property is used to set or remove decorations from text. It's a shorthand for several properties.

None: No decoration. This link has its underline removed.

Underline: A line is drawn underneath the text.

Overline: A line is drawn above the text.

Line-through: A line is drawn through the middle of the text.

Combined: You can combine styles, like a wavy red underline.
