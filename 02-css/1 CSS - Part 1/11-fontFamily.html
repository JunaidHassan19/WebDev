The CSS font-family Property

This property specifies a prioritized list of one or more font family names and/or generic family names for an element.

Font Stacks and Fallbacks

You should always provide a "font stack" — a list of fonts for the browser to try. It will use the first font in the list that is available on the user's system. Always end the list with a generic family name as a final fallback.

font-family: "Helvetica Neue", Arial, sans-serif;

1. Serif Fonts

Serif fonts have small strokes (called serifs) attached to the main part of the letters. They are often used for body text in print and can convey a sense of tradition and elegance.

This text is in a serif font (Georgia). It's often considered easy to read in long-form text.

2. Sans-Serif Fonts

"Sans" literally means "without". Sans-serif fonts do not have serifs. They are known for their clean, modern, and minimalist appearance, making them popular for web design, especially for headings and UI elements.

This text is in a sans-serif font (Verdana). It looks clean and modern on screens.

3. Monospace Fonts

In a monospace font, every character occupies the exact same amount of horizontal space. This is ideal for displaying code, as it aligns characters vertically.

This text is in a monospace font (Courier New).

Generic Font Families

It's crucial to end your font stack with one of these generic keywords to let the browser pick a suitable font if none of your specified fonts are available.

  • serif - e.g., Times New Roman, Georgia
  • sans-serif - e.g., Arial, Helvetica, Verdana
  • monospace - e.g., Courier New, Lucida Console
  • cursive - Fonts that emulate handwriting. e.g., Brush Script MT
  • fantasy - Decorative, playful fonts. e.g., Papyrus
