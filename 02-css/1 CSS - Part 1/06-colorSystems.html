CSS Color Systems

This page demonstrates the different ways you can specify colors in CSS.

1. Color Names

CSS supports 140+ standard color names. These are great for quick and readable colors.

cornflowerblue

2. RGB (Red, Green, Blue)

The RGB model defines a color by mixing red, green, and blue light. Each value ranges from 0 to 255.

rgb(100, 149, 237)

3. RGBA (Red, Green, Blue, Alpha)

RGBA is an extension of RGB with an "alpha" channel, which specifies the opacity of the color. The alpha value ranges from 0.0 (fully transparent) to 1.0 (fully opaque).

rgba(100, 149, 237, 0.7)

4. Hexadecimal (Hex)

Hex codes are a very common way to specify colors. It's a six-digit code (prefixed with #) representing the RGB values in hexadecimal format (#RRGGBB).

#6495ED

5. HSL (Hue, Saturation, Lightness)

HSL is an intuitive color model. Hue is the degree on the color wheel (0-360), Saturation is the intensity (0%-100%), and Lightness is the brightness (0%-100%).

hsl(219, 79%, 66%)

6. HSLA (Hue, Saturation, Lightness, Alpha)

Similar to RGBA, HSLA adds an alpha channel to HSL for opacity.

hsla(219, 79%, 66%, 0.7)
