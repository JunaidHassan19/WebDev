## CSS Selectors

CSS selectors are patterns used to select and style HTML elements. They are fundamental to writing CSS, as they determine which elements your styles will apply to. Understanding selectors is crucial for writing effective and efficient CSS.

---

### 1. Element Selectors (Type Selectors)

The most basic selector. It targets all elements of a specific type.

```css
p {
    color: blue;
}

h1 {
    font-size: 2em;
}
```

This applies the `color: blue;` style to all `<p>` elements and `font-size: 2em;` to all `<h1>` elements.

---

### 2. Class Selectors

Targets elements with a specific class attribute. Use a dot (.) followed by the class name.

```css
.intro {
    color: green;
}

.highlight {
    background-color: yellow;
}
```

In HTML:
```html
<p class="intro">This paragraph has the intro class.</p>
<span class="highlight">This text is highlighted.</span>
```

**Multiple classes:** An element can have multiple classes:
```html
<div class="intro highlight">This div has both classes.</div>
```

---

### 3. ID Selectors

Targets a single element with a specific ID. Use a hash (#) followed by the ID name. **Note:** IDs should be unique within a page.

```css
#header {
    background-color: navy;
    color: white;
}

#main-content {
    padding: 20px;
}
```

In HTML:
```html
<div id="header">Header Section</div>
<section id="main-content">Main Content</section>
```

---

### 4. Attribute Selectors

Target elements based on their attributes or attribute values.

```css
/* Selects all input elements */
input[type="text"] {
    border: 1px solid #ccc;
}

/* Selects all links with href starting with https */
a[href^="https"] {
    color: green;
}

/* Selects all links with href ending with .pdf */
a[href$=".pdf"] {
    color: red;
}

/* Selects all elements with a title attribute */
[title] {
    text-decoration: underline;
}

/* Selects elements with data-role attribute containing "admin" */
[data-role*="admin"] {
    font-weight: bold;
}
```

---

### 5. Pseudo-Class Selectors

These target elements based on their state or position. They start with a colon (:).

**Common Pseudo-Classes:**

```css
/* Links that haven't been visited */
a:link {
    color: blue;
}

/* Links that have been visited */
a:visited {
    color: purple;
}

/* When hovering over an element */
a:hover {
    text-decoration: underline;
}

/* When actively clicking an element */
a:active {
    color: red;
}

/* When an input field is focused */
input:focus {
    border-color: blue;
    outline: none;
}

/* First child of its parent */
li:first-child {
    font-weight: bold;
}

/* Last child of its parent */
li:last-child {
    color: gray;
}

/* Every nth child (e.g., even rows in a table) */
tr:nth-child(even) {
    background-color: #f2f2f2;
}

/* When an element is disabled */
button:disabled {
    opacity: 0.5;
    cursor: not-allowed;
}
```

---

### 6. Pseudo-Element Selectors

These target a specific part of an element. They start with double colons (::).

```css
/* First letter of text */
p::first-letter {
    font-size: 2em;
}

/* First line of text */
p::first-line {
    font-weight: bold;
}

/* Content before an element */
p::before {
    content: ">>> ";
    color: red;
}

/* Content after an element */
p::after {
    content: " <<<";
    color: red;
}

/* Selected/highlighted text */
::selection {
    background-color: yellow;
    color: black;
}

/* Placeholder text in input fields */
input::placeholder {
    color: #999;
}
```

---

### 7. Combinators

Combinators are used to select elements based on their relationship to other elements.

#### A. Descendant Combinator (space)
Selects all descendants of an element.

```css
div p {
    color: blue; /* All <p> elements inside any <div> */
}
```

#### B. Child Combinator (>)
Selects only direct children.

```css
div > p {
    color: blue; /* Only <p> elements that are direct children of <div> */
}
```

#### C. Adjacent Sibling Combinator (+)
Selects an element that is immediately preceded by another element.

```css
h2 + p {
    color: green; /* The first <p> that comes right after an <h2> */
}
```

#### D. General Sibling Combinator (~)
Selects all siblings that follow an element.

```css
h2 ~ p {
    color: green; /* All <p> elements that are siblings of <h2> */
}
```

---

### 8. The Universal Selector (*)

The universal selector matches every element on the page.

```css
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
```

This is commonly used to reset default browser styles. The universal selector has the lowest specificity (0 points).

---

### 9. Multiple Selectors (Grouping)

Apply the same styles to multiple selectors by separating them with commas.

```css
h1, h2, h3 {
    color: navy;
    font-family: Arial, sans-serif;
}

.button, button, input[type="button"] {
    padding: 10px;
    background-color: #007bff;
    color: white;
    border: none;
}
```

---

### 10. Specificity

When multiple CSS rules apply to the same element, the browser uses specificity to determine which rule wins:

- **ID selector:** 100 points
- **Class, attribute, or pseudo-class selector:** 10 points
- **Element selector:** 1 point
- **Universal selector (*):** 0 points

**Example:**
```css
#header {
    color: red;   /* Specificity: 100 */
}

.main {
    color: blue;  /* Specificity: 10 */
}

p {
    color: green; /* Specificity: 1 */
}
```

For `<p class="main" id="header">Text</p>`, the text will be red because the ID selector has the highest specificity.

---

### 11. The !important Flag

```css
p {
    color: red !important; /* This will override almost all other rules */
}
```

**Note:** Avoid using `!important` unless absolutely necessary, as it makes CSS harder to maintain.

---

### Best Practices

1. **Keep selectors simple** - Complex, deeply nested selectors are harder to maintain and less reusable.

2. **Use classes for styling** - Classes are more reusable than IDs. IDs should be used primarily for JavaScript or unique page sections.

3. **Avoid over-nesting** - Don't nest selectors more than 2-3 levels deep.

4. **Use semantic selectors** - Choose selectors that make sense in context.

5. **Organize selectors** - Group related selectors together in your CSS file.

### Quick Reference Table

| Selector | Syntax | Example |
|----------|--------|---------|
| Element | `element` | `p`, `div`, `h1` |
| Class | `.classname` | `.intro`, `.button` |
| ID | `#idname` | `#header`, `#main` |
| Attribute | `[attribute]` or `[attribute="value"]` | `[type="text"]`, `[href^="https"]` |
| Pseudo-class | `:pseudo-class` | `:hover`, `:focus`, `:first-child` |
| Pseudo-element | `::pseudo-element` | `::before`, `::after`, `::first-letter` |
| Descendant | `ancestor descendant` | `div p` |
| Child | `parent > child` | `div > p` |
| Adjacent sibling | `element + sibling` | `h2 + p` |
| General sibling | `element ~ sibling` | `h2 ~ p` |
| Universal | `*` | `*` |

---

### Conclusion

Mastering CSS selectors is essential for writing effective stylesheets. Start with the basics (element, class, and ID selectors), then gradually explore more advanced selectors like pseudo-classes, pseudo-elements, and combinators. Always aim for clarity and maintainability in your CSS.

```css
* {
    color: #333;
}

h1, h2, h3 {
    color: #0066cc; /* Override for headings */
}

a {
    color: #006400; /* Override for links */
}
```

---

### Best Practices

1. **Use for resetting styles** - The universal selector is best used at the beginning of your stylesheet to reset default browser styles.

2. **Be specific with content styling** - For actual content styling, use more specific selectors (element, class, ID) rather than the universal selector to avoid unnecessary complexity.

3. **Combine with other selectors** - You can use the universal selector in combination with other selectors:
   - `div *` - Selects all elements inside a div
   - `.container *` - Selects all elements inside elements with the class "container"
   - `* > p` - Selects all p elements that are direct children of any element

4. **Consider using a CSS reset or normalize.css** - Many developers use pre-built CSS reset files or libraries like "normalize.css" instead of creating their own universal selector reset. These provide more sophisticated and well-tested resets.

---

### Conclusion

The universal selector (*) is a powerful tool for establishing consistent baseline styles across your entire webpage. It's most effective when used sparingly for global resets and defaults, then overridden by more specific selectors for targeted styling.
