## CSS Universal Selector (*)

The universal selector (*) in CSS is a special selector that matches every element on the page. It selects all elements regardless of type, class, or ID.

---

### Basic Syntax

```css
* {
    property: value;
}
```

The asterisk (*) represents all elements on the page.

---

### Common Use Cases

#### 1. Reset Default Styles

One of the most common uses of the universal selector is to reset default browser styles. Different browsers apply slightly different default styles (called "user agent styles") to elements like margins, padding, and list bullets.

```css
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
```

**What this does:**
- `margin: 0;` - Removes all default margins from every element
- `padding: 0;` - Removes all default padding from every element
- `box-sizing: border-box;` - Changes how width and height are calculated (includes padding and border in the total width/height)

This is often the first rule in a CSS file to ensure consistency across all browsers.

#### 2. Apply Consistent Font or Color

```css
* {
    font-family: Arial, sans-serif;
    color: #333;
}
```

This ensures all elements use the same font family and text color unless overridden by more specific rules.

#### 3. Set a Base Line Height

```css
* {
    line-height: 1.6;
}
```

This applies a consistent line height to all text elements on the page.

---

### Important Notes

**Performance Consideration:**
While the universal selector is very useful, be cautious when using it with complex property values on large websites, as it has to apply to every single element. This can slightly impact performance. However, for simple properties like margin reset, the impact is negligible.

**Specificity:**
The universal selector has the lowest specificity (0, 0, 0), meaning it will be overridden by any other CSS rule. This makes it perfect for setting default values that can be easily customized for specific elements.

---

### Examples

#### Example 1: Basic Reset

```css
* {
    margin: 0;
    padding: 0;
}

body {
    font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
    line-height: 1.5;
}
```

#### Example 2: Setting Box Model

```css
* {
    box-sizing: border-box;
}
```

This makes `width` and `height` include borders and padding, making sizing calculations more intuitive.

#### Example 3: Universal Styling with Overrides

```css
* {
    color: #333;
}

h1, h2, h3 {
    color: #0066cc; /* Override for headings */
}

a {
    color: #006400; /* Override for links */
}
```

---

### Best Practices

1. **Use for resetting styles** - The universal selector is best used at the beginning of your stylesheet to reset default browser styles.

2. **Be specific with content styling** - For actual content styling, use more specific selectors (element, class, ID) rather than the universal selector to avoid unnecessary complexity.

3. **Combine with other selectors** - You can use the universal selector in combination with other selectors:
   - `div *` - Selects all elements inside a div
   - `.container *` - Selects all elements inside elements with the class "container"
   - `* > p` - Selects all p elements that are direct children of any element

4. **Consider using a CSS reset or normalize.css** - Many developers use pre-built CSS reset files or libraries like "normalize.css" instead of creating their own universal selector reset. These provide more sophisticated and well-tested resets.

---

### Conclusion

The universal selector (*) is a powerful tool for establishing consistent baseline styles across your entire webpage. It's most effective when used sparingly for global resets and defaults, then overridden by more specific selectors for targeted styling.
