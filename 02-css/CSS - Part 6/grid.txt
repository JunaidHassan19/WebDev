## CSS Grid

CSS Grid is a powerful two-dimensional layout system that allows you to create complex layouts with rows and columns. It provides precise control over positioning and alignment, making it ideal for page layouts and structured designs.

---

## What is CSS Grid?

CSS Grid is a layout method for creating grid-based designs. It allows you to:
- Arrange items in rows and columns simultaneously
- Create complex, responsive layouts easily
- Precisely position and align items
- Manage spacing and alignment automatically

---

## Key Concepts

### Grid Container vs Grid Items

- **Grid Container** - The parent element that holds grid items. Created by setting `display: grid;`
- **Grid Items** - Direct children of the grid container

### Grid Terminology

- **Grid Track** - A row or column in the grid
- **Grid Line** - Horizontal or vertical line dividing the grid
- **Grid Cell** - The intersection of a row and column (smallest unit)
- **Grid Area** - Multiple cells combined

```
Grid Lines (vertical)
    ↓        ↓        ↓
    |--------|--------|
  ↓ |  Cell  |  Cell  |  ← Grid Track (row)
    |--------|--------|  ← Grid Line (horizontal)
  ↓ |  Cell  |  Cell  |
    |--------|--------|

    ↑ Grid Track (column)
```

## Defining the Grid

### 1. display: grid

Creates a grid container:

```css
.container {
    display: grid;
}
```

### 2. grid-template-columns

Defines the number and size of columns:

```css
.container {
    grid-template-columns: 200px 300px 150px;        /* Fixed widths */
    grid-template-columns: 1fr 1fr 1fr;              /* Equal fractions */
    grid-template-columns: repeat(3, 1fr);           /* Repeat 3 times */
    grid-template-columns: repeat(auto-fit, 200px);  /* Responsive */
    grid-template-columns: 200px 1fr 200px;          /* Mixed */
    grid-template-columns: minmax(200px, 1fr);       /* Min and max */
}
```

### 3. grid-template-rows

Defines the number and size of rows:

```css
.container {
    grid-template-rows: 100px 200px 150px;    /* Fixed heights */
    grid-template-rows: auto 200px auto;      /* Auto sizing */
    grid-template-rows: repeat(3, 1fr);       /* Equal fractions */
}
```

### 4. gap (or grid-gap)

Sets space between rows and columns:

```css
.container {
    gap: 20px;              /* Space between all items */
    gap: 20px 30px;         /* Row gap 20px, Column gap 30px */
    row-gap: 20px;
    column-gap: 30px;
}
```

## Grid Container Properties

### 5. justify-items

Aligns grid items horizontally within their cells:

```css
.container {
    justify-items: start;     /* Items aligned to left */
    justify-items: end;       /* Items aligned to right */
    justify-items: center;    /* Items centered */
    justify-items: stretch;   /* Items stretch to fill */
}
```

### 6. align-items

Aligns grid items vertically within their cells:

```css
.container {
    align-items: start;       /* Items aligned to top */
    align-items: end;         /* Items aligned to bottom */
    align-items: center;      /* Items centered vertically */
    align-items: stretch;     /* Items stretch to fill */
}
```

### 7. justify-content

Aligns the entire grid horizontally within the container:

```css
.container {
    justify-content: start;
    justify-content: end;
    justify-content: center;
    justify-content: space-between;
    justify-content: space-around;
    justify-content: space-evenly;
}
```

### 8. align-content

Aligns the entire grid vertically within the container:

```css
.container {
    align-content: start;
    align-content: end;
    align-content: center;
    align-content: space-between;
    align-content: space-around;
    align-content: space-evenly;
}
```

### 9. grid-auto-flow

Determines how items are automatically placed:

```css
.container {
    grid-auto-flow: row;         /* Default: fill rows */
    grid-auto-flow: column;      /* Fill columns */
    grid-auto-flow: row dense;   /* Fill gaps in rows */
    grid-auto-flow: column dense;/* Fill gaps in columns */
}
```

### 10. grid-auto-columns and grid-auto-rows

Sets size for implicitly created tracks:

```css
.container {
    grid-auto-columns: 200px;
    grid-auto-rows: 150px;
}
```

## Grid Item Properties

### 1. grid-column

Specifies which column(s) an item occupies:

```css
.item {
    grid-column: 1;              /* Start at column 1 */
    grid-column: 1 / 3;          /* From column 1 to column 3 */
    grid-column: span 2;         /* Span 2 columns */
    grid-column: 2 / span 3;     /* Start at column 2, span 3 */
}
```

### 2. grid-row

Specifies which row(s) an item occupies:

```css
.item {
    grid-row: 1;                 /* Start at row 1 */
    grid-row: 1 / 3;             /* From row 1 to row 3 */
    grid-row: span 2;            /* Span 2 rows */
}
```

### 3. grid-area

Shorthand for `grid-column` and `grid-row`:

```css
.item {
    grid-area: 1 / 1 / 3 / 3;  /* row-start / column-start / row-end / column-end */
}
```

### 4. justify-self

Overrides `justify-items` for a specific item:

```css
.item {
    justify-self: start;
    justify-self: end;
    justify-self: center;
    justify-self: stretch;
}
```

### 5. align-self

Overrides `align-items` for a specific item:

```css
.item {
    align-self: start;
    align-self: end;
    align-self: center;
    align-self: stretch;
}
```

---

## fr Unit (Fraction)

The `fr` unit represents a fraction of the available space:

```css
.container {
    grid-template-columns: 1fr 2fr 1fr;
    /* Total space is 4 parts: 1st item gets 1/4, 2nd gets 2/4, 3rd gets 1/4 */
}
```

---

## repeat() Function

Simplifies repetitive grid definitions:

```css
.container {
    grid-template-columns: repeat(3, 1fr);
    /* Same as: 1fr 1fr 1fr */
    
    grid-template-columns: repeat(3, 200px 1fr);
    /* Same as: 200px 1fr 200px 1fr 200px 1fr */
}
```

---

## minmax() Function

Defines minimum and maximum sizes:

```css
.container {
    grid-template-columns: minmax(200px, 1fr) minmax(200px, 1fr);
    /* Each column is at least 200px, but can grow */
}
```

---

## auto-fit and auto-fill

Create responsive grids without media queries:

```css
/* auto-fit: collapses empty tracks */
.container {
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
}

/* auto-fill: keeps empty tracks */
.container {
    grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
}
```

## Practical Examples

### Example 1: Simple 3x3 Grid

```css
.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-template-rows: repeat(3, 100px);
    gap: 10px;
}

.item {
    background-color: lightblue;
    border: 1px solid blue;
}
```

### Example 2: Responsive Grid

```css
.container {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    gap: 20px;
    padding: 20px;
}

.item {
    background-color: lightgreen;
    padding: 20px;
}
```

### Example 3: Spanning Columns and Rows

```css
.container {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    gap: 10px;
}

.header {
    grid-column: 1 / -1;  /* Span all columns */
}

.sidebar {
    grid-row: span 2;     /* Span 2 rows */
}

.main-content {
    grid-column: 2 / -1;  /* From column 2 to end */
}
```

### Example 4: Named Grid Areas

```css
.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 10px;
    grid-template-areas:
        "header header header"
        "sidebar main main"
        "footer footer footer";
}

.header {
    grid-area: header;
}

.sidebar {
    grid-area: sidebar;
}

.main {
    grid-area: main;
}

.footer {
    grid-area: footer;
}
```

### Example 5: Complex Layout

```css
.container {
    display: grid;
    grid-template-columns: 200px 1fr 200px;
    grid-template-rows: auto 1fr auto;
    height: 100vh;
    gap: 20px;
}

.header {
    grid-column: 1 / -1;
    background-color: navy;
    color: white;
    padding: 20px;
}

.sidebar-left {
    background-color: lightgray;
    padding: 20px;
}

.main-content {
    background-color: white;
    padding: 20px;
    overflow-y: auto;
}

.sidebar-right {
    background-color: lightgray;
    padding: 20px;
}

.footer {
    grid-column: 1 / -1;
    background-color: navy;
    color: white;
    padding: 20px;
    text-align: center;
}
```

## Grid vs Flexbox

| Aspect | Grid | Flexbox |
|---|---|---|
| Dimensions | Two-dimensional | One-dimensional |
| Use Case | Page layouts, structured designs | Navigation, toolbars, single row/column |
| Container Control | High (explicit positioning) | Flexible (reactive to content) |
| Complexity | Can be more complex | Simpler for one-direction layouts |
| Best For | Overall page structure | Component alignment |

**When to use Grid:**
- Complex layouts with rows AND columns
- Page structure (header, sidebar, main, footer)
- Dashboard or admin panel layouts

**When to use Flexbox:**
- Simple one-dimensional layouts
- Navigation bars and toolbars
- Centering content
- Component styling

## Browser Support

CSS Grid is well-supported in all modern browsers. For older browsers:

```css
.container {
    display: -ms-grid;  /* Internet Explorer 10+ */
    display: grid;
}
```

## Common Issues and Solutions

### Issue 1: Items Not Aligning Properly

**Problem:**
```css
.container {
    display: grid;
    grid-template-columns: 1fr 1fr;
}
```

**Solution:**
```css
.container {
    display: grid;
    grid-template-columns: 1fr 1fr;
    align-items: stretch;  /* Make items fill cells */
}
```

### Issue 2: Responsive Grid Not Working

**Problem:** Fixed columns on all screen sizes

**Solution:** Use `auto-fit` or `auto-fill`:
```css
.container {
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
}
```

### Issue 3: Grid Gaps Creating Too Much Space

**Problem:** Too much space between items

**Solution:** Reduce gap value:
```css
.container {
    gap: 10px;  /* Reduce from default */
}
```

## Best Practices

1. **Use Grid for layouts, Flexbox for components** - Combine both for best results.

2. **Use `fr` units for flexible layouts** - Better than percentages for responsive design.

3. **Use named grid areas for clarity** - Makes your code more readable.

4. **Use `minmax()` with `auto-fit`** - For responsive grids without media queries.

5. **Don't mix up rows and columns** - Remember: rows are horizontal, columns are vertical.

6. **Use `repeat()` to reduce repetition** - Keeps CSS cleaner.

7. **Test on multiple screen sizes** - Ensure your grid looks good everywhere.

8. **Use browser DevTools for debugging** - Firefox and Chrome have excellent Grid inspectors.

## Advanced: CSS Grid Template

```css
.page-layout {
    display: grid;
    grid-template-columns: 200px 1fr 300px;
    grid-template-rows: 80px 1fr 60px;
    gap: 20px;
    height: 100vh;
    
    grid-template-areas:
        "header header header"
        "sidebar content right-panel"
        "footer footer footer";
}

header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.content { grid-area: content; }
.right-panel { grid-area: right-panel; }
footer { grid-area: footer; }

@media (max-width: 768px) {
    .page-layout {
        grid-template-columns: 1fr;
        grid-template-areas:
            "header"
            "content"
            "footer";
    }
    
    .sidebar, .right-panel {
        display: none;
    }
}
```

## Conclusion

CSS Grid is essential for modern web layouts. It provides precise control over two-dimensional arrangements and makes responsive design easier. Combine Grid with Flexbox for powerful, flexible layouts that work on all devices and screen sizes.
