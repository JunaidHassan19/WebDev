## CSS Flexbox (Flexible Box Layout)

Flexbox is a powerful CSS layout module that makes it easier to design flexible and efficient layouts. It provides a more predictable way to arrange, distribute, and align elements in containers, even when their size is unknown or dynamic.

---

## What is Flexbox?

Flexbox is a one-dimensional layout method for arranging items in rows or columns. It offers:
- Easy alignment and distribution of space between elements
- Better responsive design without media queries
- Simplified layout structure
- Flexibility in handling different screen sizes

---

## Key Concepts

### Flex Container vs Flex Items

- **Flex Container** - The parent element that holds flex items. Created by setting `display: flex;`
- **Flex Items** - Direct children of the flex container

### Main Axis vs Cross Axis

- **Main Axis** - The primary axis along which flex items are laid out (horizontal by default)
- **Cross Axis** - Perpendicular to the main axis (vertical by default)

```
Main Axis (horizontal) →
┌─────────────────────────────┐
│ Item 1  Item 2  Item 3     │ ↓ Cross Axis (vertical)
│                            │
└─────────────────────────────┘
```

## Flexbox Properties for the Container

### 1. display: flex

Defines a flex container:

```css
.container {
    display: flex;
}
```

### 2. flex-direction

Controls the direction of flex items (main axis direction):

```css
.container {
    flex-direction: row;           /* Default: left to right */
    flex-direction: row-reverse;   /* Right to left */
    flex-direction: column;        /* Top to bottom */
    flex-direction: column-reverse; /* Bottom to top */
}
```

### 3. flex-wrap

Controls whether flex items wrap to multiple lines:

```css
.container {
    flex-wrap: nowrap;    /* Default: items stay in one line */
    flex-wrap: wrap;      /* Items wrap to next line */
    flex-wrap: wrap-reverse; /* Items wrap in reverse direction */
}
```

### 4. justify-content

Aligns items along the main axis (horizontal by default):

```css
.container {
    justify-content: flex-start;    /* Default: items at start */
    justify-content: flex-end;      /* Items at end */
    justify-content: center;        /* Items centered */
    justify-content: space-between; /* Space between items */
    justify-content: space-around;  /* Space around items */
    justify-content: space-evenly;  /* Equal space everywhere */
}
```

### 5. align-items

Aligns items along the cross axis (vertical by default):

```css
.container {
    align-items: flex-start;   /* Items at start of cross axis */
    align-items: flex-end;     /* Items at end of cross axis */
    align-items: center;       /* Items centered on cross axis */
    align-items: stretch;      /* Default: items stretch to fill */
    align-items: baseline;     /* Items aligned to baseline */
}
```

### 6. align-content

Controls alignment of multiple lines (when flex-wrap is used):

```css
.container {
    align-content: flex-start;
    align-content: flex-end;
    align-content: center;
    align-content: space-between;
    align-content: space-around;
    align-content: stretch;
}
```

### 7. gap

Sets space between flex items:

```css
.container {
    gap: 20px;              /* Space between all items */
    gap: 20px 30px;         /* Row gap 20px, Column gap 30px */
    row-gap: 20px;
    column-gap: 30px;
}
```

### 8. flex-flow

Shorthand for `flex-direction` and `flex-wrap`:

```css
.container {
    flex-flow: row wrap;
    /* Same as: 
       flex-direction: row;
       flex-wrap: wrap;
    */
}
```

## Flexbox Properties for Items (Children)

### 1. flex-grow

Defines how much an item will grow relative to other items:

```css
.item {
    flex-grow: 0;  /* Default: doesn't grow */
    flex-grow: 1;  /* Will grow to fill available space */
    flex-grow: 2;  /* Grows twice as much as flex-grow: 1 */
}
```

### 2. flex-shrink

Defines how much an item will shrink relative to other items:

```css
.item {
    flex-shrink: 1;  /* Default: shrinks equally */
    flex-shrink: 0;  /* Won't shrink */
    flex-shrink: 2;  /* Shrinks twice as much */
}
```

### 3. flex-basis

Sets the default size of an item before remaining space is distributed:

```css
.item {
    flex-basis: 200px;      /* Set base width */
    flex-basis: 30%;        /* Set as percentage */
    flex-basis: auto;       /* Default: use width/height */
}
```

### 4. flex

Shorthand for `flex-grow`, `flex-shrink`, and `flex-basis`:

```css
.item {
    flex: 1;              /* flex-grow: 1, flex-shrink: 1, flex-basis: 0 */
    flex: 0 0 200px;      /* flex-grow: 0, flex-shrink: 0, flex-basis: 200px */
    flex: 1 0 auto;       /* flex-grow: 1, flex-shrink: 0, flex-basis: auto */
}
```

### 5. align-self

Overrides `align-items` for a specific item:

```css
.item {
    align-self: flex-start;
    align-self: flex-end;
    align-self: center;
    align-self: stretch;
}
```

### 6. order

Changes the order of items without modifying HTML:

```css
.item-1 {
    order: 3;   /* Will appear third */
}

.item-2 {
    order: 1;   /* Will appear first */
}

.item-3 {
    order: 2;   /* Will appear second */
}
```

## Practical Examples

### Example 1: Centered Content

```css
.container {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 300px;
    background-color: lightgray;
}

.item {
    background-color: blue;
    padding: 20px;
}
```

### Example 2: Navigation Bar

```css
nav {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 10px 20px;
    background-color: navy;
}

nav a {
    color: white;
    text-decoration: none;
    margin: 0 15px;
}

nav .logo {
    font-weight: bold;
    font-size: 1.5em;
}
```

### Example 3: Flexible Grid

```css
.grid {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
}

.grid-item {
    flex: 1;
    min-width: 250px;
    background-color: lightblue;
    padding: 20px;
}
```

### Example 4: Sidebar Layout

```css
.layout {
    display: flex;
    height: 100vh;
}

.sidebar {
    width: 200px;
    background-color: #f0f0f0;
    padding: 20px;
}

.main-content {
    flex: 1;
    padding: 20px;
    overflow-y: auto;
}
```

### Example 5: Equal Width Columns

```css
.columns {
    display: flex;
    gap: 20px;
}

.column {
    flex: 1;  /* Each column takes equal space */
    background-color: lightgreen;
    padding: 20px;
}
```

## Common Flexbox Patterns

### Vertical Center and Justify

```css
.container {
    display: flex;
    justify-content: center;  /* Horizontal center */
    align-items: center;      /* Vertical center */
    height: 300px;
}
```

### Space Between Elements

```css
.container {
    display: flex;
    justify-content: space-between;
}
```

### Flexible Growing Items

```css
.container {
    display: flex;
    gap: 10px;
}

.item {
    flex: 1;  /* All items grow equally */
}
```

### Fixed Width and Flexible

```css
.container {
    display: flex;
    gap: 10px;
}

.fixed {
    width: 200px;
}

.flexible {
    flex: 1;  /* Takes remaining space */
}
```

## Flexbox vs Grid

| Aspect | Flexbox | Grid |
|---|---|---|
| Dimensions | One-dimensional | Two-dimensional |
| Use Case | Navigation, toolbars, simple layouts | Complex layouts, page structure |
| Main Axis | Flexible (row or column) | Both axes explicit |
| Item Alignment | Flexible | More control |

---

## Browser Support

Flexbox is well-supported in all modern browsers. For older browsers, add the prefix:

```css
.container {
    display: -webkit-flex;  /* Safari, older Chrome */
    display: flex;
}
```

---

## Best Practices

1. **Use flexbox for one-dimensional layouts** - When arranging items in a row or column.

2. **Combine with Grid for complex layouts** - Use Grid for 2D layouts and Flexbox for components.

3. **Use `flex` shorthand** - It's cleaner than individual properties.

4. **Remember the main and cross axes** - Helps understand alignment properties.

5. **Use `gap` for spacing** - Cleaner than margins on individual items.

6. **Don't rely on HTML order** - Use `order` for visual arrangement, but keep HTML logical.

7. **Set min-width on flex items** - Prevents items from shrinking below content size.

8. **Use `justify-content` and `align-items` effectively** - These are the most used properties.

---

## Common Issues and Solutions

### Issue 1: Items Not Shrinking Below Content Size

**Problem:**
```css
.item {
    flex: 1;
}
```

**Solution:**
```css
.item {
    flex: 1;
    min-width: 0;  /* Allow items to shrink below content */
}
```

### Issue 2: Items Not Centering in Container

**Problem:**
```css
.container {
    display: flex;
}
```

**Solution:**
```css
.container {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 300px;  /* Container needs height */
}
```

### Issue 3: Gap Not Working

**Problem:** Gap doesn't work with inline-flex

**Solution:** Use `display: flex;` instead of `display: inline-flex;`

---

## Conclusion

Flexbox is an essential CSS tool for modern web layouts. It simplifies alignment, spacing, and responsive design. Master the container properties (`justify-content`, `align-items`) and item properties (`flex`, `order`), and you'll be able to build flexible, maintainable layouts efficiently.
